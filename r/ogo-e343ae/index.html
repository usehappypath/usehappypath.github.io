Finding an event · 12

OBS-01

Search results do not say what you searched for, and an emoji search shows everything

Should fix/ru/filtered?q=ханука desktop mobile
What we saw
After a search for "ханука" (Hanukkah) the list heading reads "Все события в Израиле" (all events in Israel), as on the home page, and the page heading is the site name, "OGO! — афиша событий в Израиле". The query appears only inside the search box, and there is no result count. A search for an emoji ("🎵🎉") shows the full event list with no "nothing found" message. A text search with no match does say "По запросу «…» ничего не нашлось".
Why it matters
A visitor cannot tell a list of results from the normal listing, so an empty search looks like a long list of matches.
Fixed when

The results page names the query and the number of results ("Результаты по «ханука»: N событий") with a way to clear it, and a query that matches nothing shows the "ничего не нашлось" message.

OBS-04

Should fix/ru/concerts desktop mobile
What we saw
On /ru/concerts, tapping "Сегодня" (today) changes the address to …/filtered?start=…&end=… but does not add a history step. OBS-14

Fix first/en/holidays/hanukkah/jerusalem desktop
What we saw
"First candle, December 4 | 4:34 PM | after sunset". 4 December 2026 is a Friday. On Friday the Hanukkah candles are lit before the Shabbat candles, so before sunset; in Jerusalem Shabbat candles are lit about 40 minutes before sunset.
