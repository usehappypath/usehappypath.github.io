Happy Path

Terms

Last updated: 24 November 2026. Happy Path is run by Podway. Contact: open a GitHub issue.

The service

Happy Path tests public pages of a website you control and files issues in GitHub repos where you install the app. It is free during early access and offered as is, without a guarantee that it finds every problem.

Your part

  • Only set up sites you control. You prove this with the file /.well-known/happypath.txt.
  • Do not use Happy Path to load-test, attack or scrape a site.

Our part

  • We test read-only and politely: no form submits, sign-ins or purchases, and a limited number of pages per day.
  • We test a limited number of sites at a time. When full, new sites join a waitlist.
  • We may pause or stop testing a site, for example if it blocks us or the setup is wrong. We say so in the setup issue.

Changes and ending

We may change these terms or end early access; we will say so on this page and in your setup issue. You can stop at any time by uninstalling the app.
